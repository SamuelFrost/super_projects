# `.agents/attributes/tools/lllm`

Guidelines for delegating work to the local LLM (`lllm`) and its subagents (`browser_agent`, `files_agent`).

| Path | Role |
|------|------|
| `treat_local_llm_as_cheap_laborer.md` | Treat `lllm` as a cheap laborer relative to coordinator actions and thoughts. |
| `delegate_to_local_llm_subagents.md` | Generic delegation, scope boundaries, and skeptical evidence verification with `lllm`. |
| `record_session_logs_and_feedback_in_local_llm_journal.md` | Write coordinator feedback in `.devcontainer/lllm/.local_only/local_llm_journal/feedback(from_AI_coordinator)/`. `lllm` writes `.devcontainer/lllm/.local_only/local_llm_journal/session_transcripts/<app>/<session id>/transcript.txt`. |
