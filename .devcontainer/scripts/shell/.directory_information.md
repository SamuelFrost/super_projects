# `.devcontainer/scripts/shell`

Scripts **sourced at runtime** from the workspace bind mount (`/super_projects_development/.devcontainer/scripts/shell/...`). They are not `COPY`’d into the image, so edits apply without rebuilding.

| Script | Purpose |
|--------|---------|
| `mise-shell-init.sh` | Prefer mise shims and activate mise for interactive bash |

Wired from the image `~/.bashrc` (Dockerfile).
