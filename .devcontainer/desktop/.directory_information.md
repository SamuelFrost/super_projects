# `.devcontainer/desktop`

Desktop and application-menu launchers copied into the image by the Dockerfile.
CLI entries open an interactive terminal in `/workspaces`.

| Launcher | Command |
|----------|---------|
| `super-projects-gemini.desktop` | `gemini` |
| `super-projects-codex.desktop` | `codex` |
| `super-projects-cursor.desktop` | `agent` |
| `super-projects-claude.desktop` | `claude` |
| `super-projects-lllm.desktop` | `lllm` |
| `super-projects-lllm-browser.desktop` | `lllm --agent=browser_agent` |
| `super-projects-lllm-web.desktop` | `lllm web` in a terminal |
| `super-projects-lllm-web-gui.desktop` | Chrome → `http://127.0.0.1:8000` |

`icons/` contains unmodified official brand assets, installed under `/usr/local/share/icons/super-projects/`:

| Asset | Official source |
|-------|-----------------|
| `gemini.svg` | [Gemini CLI brand kit](https://geminicli.com/brand-kit/), [SVG](https://geminicli.com/brandassets/gemini-cli-icon_full-color.svg) |
| `cursor.svg` | [Cursor](https://cursor.com/brand), [SVG](https://cursor.com/marketing-static/favicon-light.svg) |
| `claude.svg` | [Claude favicon](https://claude.ai/favicon.svg) |
| `gemini-app.svg` | [Google Gemini asset](https://www.gstatic.com/lamda/images/gemini_sparkle_v002_d4735304ff6292a690345.svg) |

Codex CLI uses the `chatgpt` icon supplied by OpenAI's Linux desktop package.

The `workspaces.desktop` folder shortcut opens `file:///workspaces`.
Native VS Code, Cursor, ChatGPT, and Claude Desktop entries come from their Linux
packages. The Dockerfile adapts them for software rendering in the virtual
desktop; VS Code and Cursor open `/workspaces` in an X11 window.
`super-projects-gemini-app.desktop` opens Gemini in a Chrome app window using
the persisted browser profile.

`autostart/super-projects-keyring.desktop` starts Secret Service in the XFCE
session. Its credentials live in the `desktop-keyrings` volume.

Start `lllm Web Server` before opening `lllm web GUI`. Closing the server terminal
stops the server. The GUI uses the persisted Chrome profile.
