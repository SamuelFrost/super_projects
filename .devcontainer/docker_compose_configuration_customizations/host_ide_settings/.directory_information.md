# Host IDE user settings

`write-compose-host-ide-settings` runs through the host `initializeCommand` and
writes the ignored `compose.host-ide-settings.yaml` loaded by `devcontainer.json`.
It detects existing VS Code and Cursor `settings.json` and `keybindings.json`
files and mounts them read-only, into their matching desktop profiles. No host chat database or entire
profile directory is mounted. Missing profiles and unsupported execution contexts
fall back to the normal container preferences.

It follows the POSIX shell hook and generated Compose layer pattern used by the
host filesystem compatibility setup.

See [host user settings](../../persist/README.md#host-user-settings) for user-facing
behavior, optional overrides, and file-bind limitations.
