# `.devcontainer/scripts/dockerfile`

Scripts **copied into the image** by `.devcontainer/Dockerfile` (typically under `/usr/local/bin`).

| Script | Install path | Purpose |
|--------|--------------|---------|
| `chrome` | `/usr/local/bin/chrome` | Container-safe Chrome launcher + remote debugging |
| `start-vnc` | `/usr/local/bin/start-vnc` | Xvfb + XFCE + x11vnc + noVNC |
| `ensure-auth` | `/usr/local/bin/ensure-auth` | Report host-forwarded SSH agent + `gh` status |
| `print-cursor-worker-hint` | `/usr/local/bin/print-cursor-worker-hint` | Cursor Cloud Agent worker hint (`${SUPER_PROJECTS_NAME}_devcontainer` from container env, not the host override file) |
| `localhost-forward.sh` | `/usr/local/bin/start-localhost-forwards` | Watcher that mirrors workspace Compose `ports:` onto `127.0.0.1` |
| `localhost-forward-proxy.py` | `/usr/local/lib/localhost-forward-proxy.py` | TCP proxy used when `socat` is not installed |

Compose and `postStartCommand` invoke helpers by **installed name** (e.g. `ensure-auth`) or, for localhost forwards, the workspace script path so git pull applies without an image rebuild. `SSH_AUTH_SOCK` comes from Compose `environment`; OpenSSH also uses `IdentityAgent /ssh-agent.sock` in the image ssh config.

See `.devcontainer/localhost-forwards.md`. Projects in the workspace do not join the parent network or maintain a forwarder config file.
