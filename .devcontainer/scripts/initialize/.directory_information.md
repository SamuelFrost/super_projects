# `.devcontainer/scripts/initialize`

Scripts run on the **host** by `devcontainer.json` `initializeCommand` before the container is created (VS Code, Cursor, and `devcontainer up`).

| Script | Purpose |
|--------|---------|
| `ensure-host-ssh-agent` | Write `.devcontainer/.env` (`DEVELOPER_UID`, `DOCKER_GID`, `HOST_HOME_DIR`, `HOST_SSH_AUTH_SOCK`); ensure host ssh-agent; load/unlock default keys when possible |

Do not require developers to run this manually for normal setup; it is a hook of the existing Dev Containers flow. To unlock keys again after the agent is cleared, reopen the folder in the container (re-runs initializeCommand).
