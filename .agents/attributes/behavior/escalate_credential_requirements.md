# Escalate Credential Requirements - if a credential is required, stop and ask the user to handle it

- Inform the user of the standard login process and ask them to handle it.
- Do not ask the user to provide a password or key.
- Do not search for credentials or work-arounds.
- If the work can be accomplished without the elevated privileges from credentials and without bypassing any standard human user flows, you may do so. 
- Never attempt to bypass the intended security of a system.
