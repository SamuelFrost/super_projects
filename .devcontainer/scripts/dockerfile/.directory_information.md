# `.devcontainer/scripts/dockerfile`

Scripts **copied into the image** by `.devcontainer/Dockerfile` (typically under `/usr/local/bin`).

| Script | Install path | Purpose |
|--------|--------------|---------|
| `kasmvnc-clipboard.js` | `/usr/share/kasmvnc/www/clipboard-settings.js` | Select manual clipboard transfers before the web client initializes |
| `chrome` | `/usr/local/bin/chrome` | Container-safe Chrome launcher + remote debugging |
| `start-vnc` | `/usr/local/bin/start-vnc` | Start or reconnect to KasmVNC + XFCE |
| `desktop-session` | `/usr/local/bin/desktop-session` | Manage the X display, XFCE, and shared session bus (invoked by `start-vnc`) |
| `ensure-auth` | `/usr/local/bin/ensure-auth` | Report host-forwarded SSH agent + `gh` status |
| `gui-startup` | `/usr/local/bin/gui-startup` | Start the desktop; optionally restart the GUI tunnel and display its URL |

Compose invokes helpers by **installed name** (e.g. `ensure-auth`). `SSH_AUTH_SOCK` comes from Compose `environment`; OpenSSH also uses `IdentityAgent /ssh-agent.sock` in the image ssh config.

Localhost port mirroring is the `localhost_forward_proxy` sidecar, not an image-installed script — see `../localhost_forward_proxy/.directory_information.md`.

`gui` is installed at `/usr/local/bin/gui`; `gui devtunnel` checks login and uses Questionary for a single scrolling picker of `TUNNEL_ID`, a random ID, typed IDs, and saved account IDs. Listing an ID does not imply active hosting. GUI-scoped native CLI state persists in `devtunnel-data` under `gui/DevTunnels`; the picker filters the standard `super-projects-gui` label. Plain CLI state stays separate. A second picker selects a saved/current region, a manual cluster code, or one of six common regions. An explicit ID bypasses the menus; `--region` sets its region. `gui devtunnel restart` relaunches the latest local GUI host, or starts the saved GUI ID if none is running. Hosting continues until stopped.

The standard Compose startup invokes `gui-startup`, which starts VNC and XFCE before handling optional remote access, including when started through `./not_devcontainer`. A display-only Dev Containers post-start hook uses `./not_devcontainer --skip-initialize` to follow actual Compose service logs for up to 45 seconds; any key stops the display early. It does not start or restart services or cache output. With `GUI_DEVTUNNEL_AUTOSTART=true`, it waits for desktop readiness, starts `gui devtunnel restart` in the background, and prints the ready URL.
