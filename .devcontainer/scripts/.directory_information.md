# `.devcontainer/scripts`

Host and image helper scripts for the super_projects devcontainer, grouped by **how they are invoked**.

| Directory | Used by | Role |
|-----------|---------|------|
| [`dockerfile/`](dockerfile/) | `.devcontainer/Dockerfile` (`COPY` into the image) | Binaries/profile snippets installed at image build time |
| [`shell/`](shell/) | `devcontainer.json` `initializeCommand` (host); interactive shells via workspace bind | Host init scripts and runtime-sourced shell helpers |
| [`localhost_forward_proxy/`](localhost_forward_proxy/) | `.devcontainer/compose.yaml` service `localhost_forward_proxy` | Ruby sidecar that mirrors workspace Compose `ports:` onto `127.0.0.1` in the parent |

Compose (`compose.yaml`) calls image-installed commands such as `ensure-auth` and `start-vnc` (from `dockerfile/`). Localhost forwards run as a sibling Compose service so they can be stopped without restarting the parent (`docker compose -f .devcontainer/compose.yaml stop localhost_forward_proxy`). The sidecar bind-mounts the workspace copy of the Ruby project so git pull applies without rebuilding that image. Interactive shells source `shell/mise-shell-init.sh` via the image `~/.bashrc`.
