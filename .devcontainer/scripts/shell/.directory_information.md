# `.devcontainer/scripts/shell`

Shell scripts under the workspace bind mount (`/workspaces/.devcontainer/scripts/shell/...`). They are not `COPY`’d into the image, so edits apply without rebuilding.

| Script | Used by | Purpose |
|--------|---------|---------|
| `initializeCommand.sh` | `devcontainer.json` `initializeCommand` (host, before container start) | Run host init steps: ssh-agent Compose file, other generated Compose files, persist dir stubs |
| `mise-shell-init.sh` | Image `~/.bashrc` (interactive bash) | Prefer mise shims and activate mise |
| `chrome-devtools-mcp` | `.cursor/mcp.json`, `.vscode/mcp.json`, `.codex/config.toml`, `.gemini/settings.json` | `development` and `browsing` launchers for Chrome DevTools MCP against desktop Chrome, and `pwa` for a separate pipe-launched Chrome. Runs `mise exec -C` on the workspace root so the `.mise.toml` pin applies when the editor’s cwd is outside the workspace |

Do not require developers to run `initializeCommand.sh` manually; VS Code, Cursor, and `devcontainer up` invoke it automatically.
