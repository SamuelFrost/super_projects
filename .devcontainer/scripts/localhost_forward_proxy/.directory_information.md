# `.devcontainer/scripts/localhost_forward_proxy`

Ruby sidecar that mirrors published `ports:` of docker compose stacks in the workspace onto `127.0.0.1` in the parent devcontainer.

| Path | Role |
|------|------|
| `bin/localhost_forward_proxy` | Process entrypoint (Compose `command:`) |
| `lib/` | Watcher, Docker CLI wrapper, discovery, TCP proxy |
| `Dockerfile` | Sidecar image (`ruby:4.0.7-alpine` + `docker-cli`) |
| `.mise.toml` | Pins Ruby 4.0.7 for tests (`mise test` from this directory) |
| `test/localhost_forward_proxy_test.rb` | Checks for discovery rules and the TCP proxy |

Started by `.devcontainer/compose.yaml` as service `localhost_forward_proxy`. It shares the parent network namespace (`network_mode: service:devcontainer`), the host Docker socket, and the workspace bind. Stop it with `docker compose --project-directory .devcontainer -f .devcontainer/compose.yaml stop localhost_forward_proxy`.

See `.devcontainer/localhost-forwards.md`.
