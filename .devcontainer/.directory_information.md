# `.devcontainer`

Devcontainer definition for super_projects.

| Path | Role |
|------|------|
| `Dockerfile` | Image build (tools, desktop/VNC, Chrome, mise, CLIs) |
| `compose.yaml` | Service, named volumes, host agent + `known_hosts` mounts, startup command |
| `devcontainer.json` | IDE/CLI integration; `initializeCommand` / `postStartCommand` |
| `scripts/` | Helpers by invocation site (`dockerfile/`, `initialize/`, `shell/`) — see `scripts/.directory_information.md` |
| `persist/` | Dual-mount shortcuts + README for named-volume state (data lives in Docker volumes) |
| `.env` | Generated on the host by `initializeCommand` (gitignored); not committed |

Compose reads `.env` next to `compose.yaml` for `${DEVELOPER_UID}`, `${DOCKER_GID}`, `${HOST_HOME_DIR}`, and `${HOST_SSH_AUTH_SOCK}`.
