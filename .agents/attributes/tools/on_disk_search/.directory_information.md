# `.agents/attributes/tools/on_disk_search`

How file and content search behaves around nested project directories ignored by the workspace `.gitignore`.

| Path | Role |
|------|------|
| `ripgrep_follows_gitignore_of_search_root.md` | Fast recursive search (`rg`). |
| `glob_returns_no_files_in_gitignored_nested_projects.md` | File-name search. |
| `grep_returns_no_matches_in_gitignored_nested_projects.md` | Content search. |
