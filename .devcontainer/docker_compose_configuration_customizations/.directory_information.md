# `.devcontainer/docker_compose_configuration_customizations`

Compose files and scripts to generate the files that `devcontainer.json` loads after `compose.yaml`. Files listed later in the compose chain replace earlier values for the same keys.

| Path | Role |
|------|------|
| `naming/create_override_file_if_missing` | called by `initializeCommand.sh`. Creates an empty `naming/compose.naming.override.yaml` when it is missing. |
| `naming/compose.naming.override.example.yaml` | Copy to `naming/compose.naming.override.yaml` and set this clone's name. |
| `naming/compose.naming.override.yaml` | Gitignored. Replaces the default name, hostname, and network name. The host ssh-agent socket filename uses this name when the file exists. |
| `host_filesystem_compatibility/write-compose-user-ids` | called by `initializeCommand.sh`. Writes `host_filesystem_compatibility/compose.user-ids.yaml` (gitignored): developer uid and Docker group id. |
| `host_filesystem_compatibility/write-compose-project-directory` | called by `initializeCommand.sh`. Writes `host_filesystem_compatibility/compose.project-directory.yaml` (gitignored): repository directory bind-mounted at `/workspaces`. The workspace path is a host filesystem path so the bind works when Docker runs in WSL2 on a Windows machine, where the path inside the devcontainer is not the path the Docker daemon can mount. |
| `ssh_agent_socket/write-compose-ssh-agent-socket` | called by `initializeCommand.sh`. Selects or starts the host ssh-agent and writes `ssh_agent_socket/compose.ssh-agent-socket.yaml` (gitignored): `HOST_SSH_AUTH_SOCK` and the `/ssh-agent.sock` bind. Inside a devcontainer that path is read from the enclosing devcontainer's copy of this file. |
| `ssh_known_hosts/write-compose-ssh-known-hosts` | called by `initializeCommand.sh`. Writes `ssh_known_hosts/compose.ssh-known-hosts.yaml` (gitignored): host `known_hosts` bind-mounted read-only. |
| `gemma/compose.gemma.yaml` | Tracked Gemma 4 service (Ollama) on the `super_projects_default` network. Default is `gemma4:e2b` with `mem_limit: 12g`, and the devcontainer client points at `http://gemma:11434`. `profiles: ["gemma"]` is commented out. Uncomment it to start Gemma only when `COMPOSE_PROFILES=gemma`. |
| `gemma/compose.gemma.override.example.yaml` | Copy to `gemma/compose.gemma.override.yaml` and set `mem_limit` and a local `gemma4` tag. |
| `gemma/local_llm_spec_guideline.md` | Hardware specs check commands (Linux/macOS/Windows) and guideline tables for choosing model tag and `mem_limit`. |
| `gemma/create_override_file_if_missing` | called by `initializeCommand.sh`. Creates an empty `gemma/compose.gemma.override.yaml` when it is missing. |
| `gemma/compose.gemma.override.yaml` | Gitignored. Empty until the example is copied over it. |
| `miscellaneous_overrides/create_override_file_if_missing` | called by `initializeCommand.sh`. Creates an empty `miscellaneous_overrides/compose.miscellaneous.override.yaml` when it is missing. |
| `miscellaneous_overrides/compose.miscellaneous.yaml` | Tracked miscellaneous Compose overrides. Listed after the other customizations. |
| `miscellaneous_overrides/compose.miscellaneous.override.example.yaml` | Copy to `miscellaneous_overrides/compose.miscellaneous.override.yaml` for local overrides. |
| `miscellaneous_overrides/compose.miscellaneous.override.yaml` | Gitignored. Final file in the Compose chain. Replaces `compose.miscellaneous.yaml`. |
