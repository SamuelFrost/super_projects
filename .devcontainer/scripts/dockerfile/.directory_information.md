# `.devcontainer/scripts/dockerfile`

Scripts **copied into the image** by `.devcontainer/Dockerfile` (typically under `/usr/local/bin`).

| Script | Install path | Purpose |
|--------|--------------|---------|
| `kasmvnc-clipboard.js` | `/usr/share/kasmvnc/www/clipboard-settings.js` | Select manual clipboard transfers before the web client initializes |
| `chrome` | `/usr/local/bin/chrome` | Container-safe Chrome launcher + remote debugging |
| `start-vnc` | `/usr/local/bin/start-vnc` | Start or reconnect to KasmVNC + XFCE |
| `desktop-session` | `/usr/local/bin/desktop-session` | Manage the X display, XFCE, and shared session bus (invoked by `start-vnc`) |
| `ensure-auth` | `/usr/local/bin/ensure-auth` | Report host-forwarded SSH agent + `gh` status |
| `print-cursor-worker-hint` | `/usr/local/bin/print-cursor-worker-hint` | Cursor Cloud Agent worker hint (`$(hostname)_devcontainer`; hostname is the Compose project name) |

Compose and `postStartCommand` invoke helpers by **installed name** (e.g. `ensure-auth`). `SSH_AUTH_SOCK` comes from Compose `environment`; OpenSSH also uses `IdentityAgent /ssh-agent.sock` in the image ssh config.

Localhost port mirroring is the `localhost_forward_proxy` sidecar, not an image-installed script — see `../localhost_forward_proxy/.directory_information.md`.
