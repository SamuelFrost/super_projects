# `.devcontainer/scripts/test`

Host-side CI scripts for the super_projects devcontainer. They are not `COPY`’d into the image.

| Script | Used by | Purpose |
|--------|---------|---------|
| `host-initialize-ci.sh` | `.github/workflows/host-initialize.yml` (`host initialize` jobs) | Unit-level checks for `initializeCommand` (compose config with/without `.env`, UID/GID contract, bridge↔`.env` socket parity, persist stubs, ssh-agent reuse/unlock). Linux askpass + macOS agent-only modes. |
| `devcontainer-up-ci.sh` | `.github/workflows/host-initialize.yml` (`devcontainer up` job) | End-to-end `devcontainer up` then `devcontainer exec` assertions (workspace mount, forwarded ssh-agent, docker.sock). Linux GitHub-hosted runners only. |

Skip when nested inside an outer super_projects container: the compose project name `super_projects` would collide with the running stack.
