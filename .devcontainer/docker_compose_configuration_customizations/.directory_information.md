# `.devcontainer/docker_compose_configuration_customizations`

Compose files that `devcontainer.json` loads after `compose.yaml`. Later files replace earlier values for the same keys.

| Path | Role |
|------|------|
| `naming/compose.naming.yaml` | Tracked default Compose name, hostname, network attachment, and network name (`super_projects`). |
| `naming/compose.naming.override.example.yaml` | Copy to `naming/compose.naming.override.yaml` and set this clone's name. |
| `naming/compose.naming.override.yaml` | Gitignored. Replaces the default name, hostname, and network name. The host ssh-agent socket filename uses this name when the file exists. |
| `host_filesystem_compatibility/write-compose-user-ids` | `initializeCommand.sh`. Writes `host_filesystem_compatibility/compose.user-ids.yaml` (gitignored): developer uid and Docker group id. |
| `host_filesystem_compatibility/write-compose-project-directory` | `initializeCommand.sh`. Writes `host_filesystem_compatibility/compose.project-directory.yaml` (gitignored): repository directory bind-mounted at `/workspaces`. The workspace path is a host filesystem path so the bind works when Docker runs in WSL2 on a Windows machine, where the path inside the devcontainer is not the path the Docker daemon can mount. |
| `ssh_agent_socket/write-compose-ssh-agent-socket` | `initializeCommand.sh`. Selects or starts the host ssh-agent and writes `ssh_agent_socket/compose.ssh-agent-socket.yaml` (gitignored): `HOST_SSH_AUTH_SOCK` and the `/ssh-agent.sock` bind. Inside a devcontainer that path is read from the enclosing devcontainer's copy of this file. |
| `ssh_known_hosts/write-compose-ssh-known-hosts` | `initializeCommand.sh`. Writes `ssh_known_hosts/compose.ssh-known-hosts.yaml` (gitignored): host `known_hosts` bind-mounted read-only. |
