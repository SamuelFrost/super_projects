# `.devcontainer/scripts/localhost_forward_proxy`

Ruby (stdlib only) sidecar that mirrors the published `ports:` of docker compose stacks in the workspace onto `127.0.0.1` in the devcontainer.

| Path | Role |
|------|------|
| `bin/localhost_forward_proxy` | Process entrypoint (Compose `command:`) |
| `lib/localhost_forward_proxy/watcher.rb` | Finds workspace stacks, attaches the devcontainer to their network so it can reach them, keeps one TCP proxy per published host port |
| `lib/localhost_forward_proxy/docker.rb` | Docker CLI wrapper (`ps`/`inspect`, `network connect`, `events`) |
| `lib/localhost_forward_proxy/tcp_proxy.rb` | `127.0.0.1:<hostPort>` → container IP:port byte copier |
| `Dockerfile` | Runtime image only (`ruby:4.0.7-alpine` + `docker-cli`); the code is bind-mounted from this directory |
| `.mise.toml` | Pins Ruby 4.0.7 for the tests (`mise test` from this directory) |
| `test/localhost_forward_proxy_test.rb` | Checks the sync rules against a fake Docker and the TCP proxy against a real socket |

Started by `.devcontainer/compose.yaml` as service `localhost_forward_proxy` with `network_mode: service:devcontainer` and the host Docker socket. Stop it with `docker compose --project-directory .devcontainer -f .devcontainer/compose.yaml stop localhost_forward_proxy`.

See `.devcontainer/localhost-forwards.md`.
