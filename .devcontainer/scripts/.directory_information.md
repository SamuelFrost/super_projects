# `.devcontainer/scripts`

Host and image helper scripts for the `${SUPER_PROJECTS_NAME}` devcontainer, grouped by **how they are invoked**.

| Directory | Used by | Role |
|-----------|---------|------|
| [`dockerfile/`](dockerfile/) | `.devcontainer/Dockerfile` (`COPY` into the image) | Binaries/profile snippets installed at image build time |
| [`shell/`](shell/) | `devcontainer.json` `initializeCommand` (host); interactive shells via workspace bind | Host init scripts and runtime-sourced shell helpers |
| [`localhost_forward_proxy/`](localhost_forward_proxy/) | `.devcontainer/compose.yaml` service `localhost_forward_proxy` | Ruby sidecar that mirrors workspace Compose `ports:` onto super_projects default network localhost — see [`localhost_forward_proxy/.directory_information.md`](localhost_forward_proxy/.directory_information.md) |

Compose (`compose.yaml`) calls image-installed commands such as `ensure-auth` and `start-vnc` (from `dockerfile/`). Localhost forwards run as a sibling Compose service so they can be stopped without restarting the devcontainer. The sidecar bind-mounts `localhost_forward_proxy/` and runs it from there, so git pull applies on its next start without rebuilding that image. Interactive shells source `shell/mise-shell-init.sh` via the image `~/.bashrc`.
