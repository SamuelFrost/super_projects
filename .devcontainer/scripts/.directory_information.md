# `.devcontainer/scripts`

Host and image helper scripts for the super_projects devcontainer, grouped by **how they are invoked**.

| Directory | Used by | Role |
|-----------|---------|------|
| [`dockerfile/`](dockerfile/) | `.devcontainer/Dockerfile` (`COPY` into the image) | Binaries/profile snippets installed at image build time |
| [`initialize/`](initialize/) | `devcontainer.json` `initializeCommand` (host, before container start) | Host `.env`, ssh-agent socket, passphrase unlock |
| [`shell/`](shell/) | Interactive shells via workspace bind (`/workspaces/...`) | Sourced at runtime; not copied into the image |

Compose (`compose.yaml`) calls image-installed commands such as `ensure-auth` and `start-vnc` (from `dockerfile/`). Interactive shells source `shell/mise-shell-init.sh` via the image `~/.bashrc`.
